# Google sign-in assets

The two PNGs in this directory are Google's pre-approved Android and web
"Sign in with Google" pill buttons at 2x resolution. They were downloaded from
the official branding bundle on 2026-08-12:

<https://developers.google.com/static/identity/images/signin-assets.zip>

Do not recolor, redraw, crop, or change the aspect ratio. When Google updates
its branding requirements, replace these files from the official bundle.
