# Security policy

## Reporting a vulnerability

Please do not disclose a suspected vulnerability in a public issue or
discussion. Report it privately through
[GitHub's security-advisory form](https://github.com/eigeninteractive/eigen-platform/security/advisories/new)
with the affected component, reproduction steps, impact, and any suggested
mitigation. We will acknowledge the report and coordinate disclosure through
that private thread.

## Supported versions

EigenInteractive is pre-1.0 software. Only packages released from the current
`eigen-platform` `main` branch receive security fixes. The archived predecessor
repositories and their older release lines are unsupported.
