# Introduction

**Eigen** is an open-source, server-authoritative engine for **turn-based
multiplayer games**. One codebase runs many games; each deployment is a single
Cloudflare Worker that owns its own domain, database, and players.

The rules run on the server, so a client's move is always a proposal the server
validates — hidden information never leaves the server except as a per-seat
projection, clocks are authoritative, and finished games are replayable from an
immutable log.

## Where things live

The project spans a few repositories, and this documentation is drawn from them:

- **Engine** — the TypeScript packages you deploy as a Worker.
- **Flutter client** — the app shell and transport that talk to the engine.
- **Games** — rules modules built on the engine (for example, the games we ship
  ourselves).

## How to read these docs

The documentation follows four shapes:

- **Getting started** — build and deploy your first game.
- **How-to guides** — task-focused recipes (rules, bots, deep links, avatars,
  push, the game website).
- **Explanation** — how the engine works and why it is built this way.
- **Reference** — the HTTP API, the TypeScript and Dart APIs, and the wire
  contract.
