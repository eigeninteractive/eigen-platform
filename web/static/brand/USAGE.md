# EigenInteractive mark: "Pruned"

One position, two continuations: one line cut short, one followed. The asymmetry
is the idea, so never mirror it or even out the two arms.

This folder is the canonical asset set. It is served from
`https://eigeninteractive.com/brand/…`, which is what npm and pub.dev READMEs
need, since neither renders relative image paths.

Everything except `USAGE.md` is generated by
[`scripts/generate-brand.mjs`](../../scripts/generate-brand.mjs) from the two
paths below. Edit the generator, run `pnpm run generate-brand`, and commit the
result; do not hand-edit the output.

### Favicons

| File | Use |
| --- | --- |
| `favicon.svg` | **The one to link.** Single file that restyles itself via `prefers-color-scheme` |
| `favicon-light.svg` / `favicon-dark.svg` | Fixed-scheme masters, heavier stroke (16%), if you need to force one |
| `favicon-16/32/64.png` | Transparent PNG favicons |
| `favicon.ico` | Legacy fallback, 16/32/48 |

A browser cannot pick between two icon *files* by colour scheme; `<link>` has no
`prefers-color-scheme` selector. Self-switching only works inside one SVG, which
is why `favicon.svg` exists and supersedes the pair.

## Colour

```
ink      #1B1E24
paper    #F4F1EA
accent   #006A60   (on light)
accent   #82D5C8   (on dark)
```

The accent is Material 3's `primary` for a `Colors.teal` seed, one value per
brightness, the same value the Flutter shell derives its whole scheme from and
the engine's public pages set `--primary` to. It is defined there and copied
here rather than the other way round: M3 pulls any seed to tone 40 and rebuilds
the ramp around it, so a hand-picked brand hex comes back as something near
itself but not itself. A mark can be drawn in a generated colour; a generated
palette cannot be talked into matching a mark.

Ink and paper carry no such obligation. They are the two grounds the mark is
drawn on, which is why the game scaffolder also uses them for launcher icons and
splash screens.

## Rules

- Clear space: one stroke width on all sides (already baked into the viewBox).
- Minimum size: 16px. Below ~40px use the `favicon.svg` master, whose 16% stroke
  keeps every limb above 3px.
- In a circular crop, the mark occupies 70% of the diameter.
- One colour beats a faded branch. Never distinguish the pruned arm by tint or
  opacity, only by length.
- Do not rotate, outline, add a gradient, or place the two-colour version on a
  mid-tone background.

### Crop safe zones

Platform crops are circles, so what matters is the mark's **circumscribed**
radius, not its bounding box. The furthest inked point from centre is the tip of
the followed arm, at **53.76%** of the box width. Insetting "to the safe-zone
percentage" is therefore wrong; it pushes that tip outside the crop. The
generator derives each scale instead:

| Target | Guaranteed region | Max scale | Used |
| --- | --- | --- | --- |
| PWA maskable | centre 80% (r = 40%) | 0.744 | 0.70 |
| Android adaptive | 66dp of 108dp (r = 30.5%) | 0.567 | 0.55 |

## Web

```html
<link rel="icon" href="/brand/favicon.svg" type="image/svg+xml">
<link rel="icon" href="/brand/favicon-32.png" sizes="32x32">
<link rel="apple-touch-icon" href="/brand/apple-touch-icon-180.png">
```

Header lockup, with the mark at cap height of the wordmark:

```html
<a href="/" style="display:flex; align-items:center; gap:16px; text-decoration:none">
  <img src="/brand/eigen-mark.svg" alt="" width="38" height="38">
  <span style="font:500 23px/1 'Space Grotesk', sans-serif; letter-spacing:-.015em; color:#1B1E24">EigenInteractive</span>
</a>
```

Or use `eigen-lockup.svg`, which bakes that same layout in with outlined text and
needs no font loaded.

One colour that follows text colour:

```html
<span style="color:#006A60">
  <img src="/brand/eigen-mark-mono.svg" width="24" height="24" alt="">
</span>
```

`currentColor` only inherits when the SVG is inlined. For `<img>`, tint with a
mask instead:

```css
.mark {
  width: 24px; height: 24px; background: currentColor;
  -webkit-mask: url(/brand/eigen-mark-mono.svg) center/contain no-repeat;
          mask: url(/brand/eigen-mark-mono.svg) center/contain no-repeat;
}
```

```jsx
    <path d="M80 160V104L48.887 72.887" stroke={ink} strokeWidth={size < 40 ? 26 : 18} strokeLinejoin="miter" />

```

## Flutter

Add `flutter_svg`, drop the SVGs in `assets/brand/`, declare them in
`pubspec.yaml`:

```dart
SvgPicture.asset('assets/brand/eigen-mark.svg', width: 38, height: 38);
```

App icons are already generated: `app-icon-1024.png` and
`app-icon-foreground-1024.png` are what `flutter_launcher_icons` expects, and
`create-eigen-game` ships both as a scaffolded game's starting icon.

## Typography

Space Grotesk Medium (500), [SIL OFL](https://openfontlicense.org). The wordmark
in `eigen-lockup*.svg` and `og-card.png` is converted to outlines, so nothing at
runtime depends on the font being available.

## Geometry (if you rebuild it)

On a 160 grid: stem from (80,160) to the fork at (80,104); followed line 100
units at +45° to (150.7, 33.3); pruned stub 44 units at −45° to (48.9, 72.9).
Stroke 18 for display, 26 for small sizes. Butt caps, mitred fork. Ratio
stub : followed = 0.44.

This section is a reconstruction aid, not the specification. The authority is
`FOLLOWED`, `PRUNED` and `VIEW_BOX` in
[`scripts/generate-brand.mjs`](../../scripts/generate-brand.mjs). If the two
ever disagree, the script is right and this prose is stale.
